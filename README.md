This is WildCat5e code for the 2025 competition

### Buttons

| Device                 | Button  | Usage                                                                       |
|------------------------|---------|-----------------------------------------------------------------------------|
| Driver Xbox Controller | Left X  | Move left joystick horizontally to control the robot translation            |
| Driver Xbox Controller | Left Y  | Move left joystick vertically to control the robot translation              |
| Driver Xbox Controller | Right X | Move right joystick horizonally to control the robot rotation               |
| Operator Numberpad     | 1       | Limelight aligns drivetrain to left reef branch                             |
| Operator Numberpad     | 3       | Limelight aligns drivetrain to right reef branch                            |
| Operator Numberpad     | 11      | Elevator moves to level 1, outtakes, and then moves back down to position 0 |
| Operator Numberpad     | 8       | Elevator moves to level 2, outtakes, and then moves back down to position 0 |
| Operator Numberpad     | 5       | Elevator moves to level 3, outtakes, and then moves back down to position 0 |
| Operator Numberpad     | 2       | Elevator moves to level 4, outtakes, and then moves back down to position 0 |
| Operator Numberpad     | 4       | Jog up                                                                      |
| Operator Numberpad     | 6       | Jog down                                                                    |
| Operator Numberpad     | 7       | Jog up                                                                      |
| Operator Numberpad     | 9       | Jog down                                                                    |
| Operator Numberpad     | 10      | Jog up                                                                      |
| Operator Numberpad     | 12      | Jog down                                                                    |
