Use Cases:
-----------
When the operator hits the RT button, the elevator will move up to the height of the coral station.

When the operator hits Y button, the elevator will move up to level one of the reef.

When the operator hits B button, the elevator will move up to level two of the reef.

When the operator hits A button, the elevator will move up to level three of the reef.

When the operator hits X button, the elevator will move up to level four of the reef.

When the operator hits LT button, the elevator will move to the correct height to pick up algae from the first level.

When the operator hits LB button, the elevator will move to the correct height to pick up algae from the second level.

When the operator hits the windows button, the elevator will move to the correct height and drop off algae to the processor.
